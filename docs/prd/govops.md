# GovOps PRD — 统一治理层

> **状态**: 原型规划，待实现

## 1. 概述

GovOps 是 OntoMind 的**统一治理平面**，覆盖跨域资产目录、安全合规、成本归因、审计日志、策略管理，确保 AI 生产环境的可管可控。

## 2. 核心场景

1. **跨域资产目录**：统一搜索代码/数据/模型/Agent 资产，支持自然语言发现
2. **跨域血缘全景**：数据→特征→模型→Agent→应用 全链路追踪
3. **AI 安全合规**：Prompt 注入防御、PII 检测、有害内容过滤、合规框架（EU AI Act/GDPR/等保）
4. **成本归因**：Token 消耗按团队/模型/用例归因，GPU 成本追踪

## 3. 页面规划

| 页面 | 说明 |
|------|------|
| **统一资产目录** | 跨域搜索 + 资产类型筛选 + 影响分析 |
| **跨域血缘全景** | 全链路血缘图（数据→特征→模型→Agent→应用） |
| **安全合规** | 安全护栏状态、合规框架检查、最近安全事件、审计日志 |
| **成本归因** | Token 成本分布、GPU 成本归因、团队预算、成本节省 |
| **审计日志** | 操作审计、配置变更记录、合规审计 |
| **策略管理** | 统一策略配置、审批流、门控规则 |

## 4. 关键设计

- 统一资产目录：支持跨域搜索 + 自然语言查询 + 影响范围分析
- 跨域血缘：血缘图支持按域筛选、时间旅行、异常节点高亮
- 安全护栏：输入过滤/输出过滤/PII 检测/Prompt 注入防御/有害内容检测
- 成本归因：按 Prompt 模板/用户段/用例/模型的 Token 归因
