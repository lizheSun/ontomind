# DataOps PRD — 数据开发流水线

> **状态**: 原型规划，待实现

## 1. 概述

DataOps 在 AI 时代的核心使命：数据不仅要进数据仓库（Analytics-Ready），还要进特征存储、向量数据库、RAG 知识库（AI-Ready）。

## 2. 核心场景

1. **数据资产全景**：数据接入→治理→特征化→服务化 全链路可视化
2. **跨域数据血缘**：数据→特征→模型→Agent→应用 全链路追踪（平台核心差异化）
3. **RAG 基础设施管理**：文档摄取、索引构建、检索质量监控、权限感知检索
4. **自然语言数据查询**：NL2SQL + Agent 思考过程可视化

## 3. 页面规划

| 页面 | 说明 |
|------|------|
| **数据资产目录** | 数据源/湖仓表/特征/向量库/知识库的统一目录 |
| **数据管线** | ETL/ELT 流水线可视化（状态 + 耗时 + 数据量） |
| **数据质量** | 五维监控（新鲜度/数据量/Schema/分布/血缘影响） |
| **数据血缘** | 三层血缘图（数据→数据 / 数据→模型 / 数据→应用） |
| **特征存储** | 特征组管理、特征服务、特征血缘、特征新鲜度 |
| **向量数据库/RAG** | 文档摄取、索引健康、检索质量（Context Precision/Recall） |
| **自然语言查询** | Agent 驱动的 NL2SQL + 结果可视化 + 追问 |

## 4. 关键设计

- 数据质量五维监控：新鲜度/数据量/Schema/分布/血缘影响（参考 Monte Carlo 标准）
- 血缘图交互：按域筛选、时间旅行、节点 drill-down
- RAG 质量：Context Precision、Context Recall、缓存命中率
